About Smooshy: Smooshy is a companion app to the online game, Smush, created by John Green and hosted at https://www.hankgreen.com/smush/. The purpose of Smooshy is to help Smush players to arrange and rearrange different combinations of Smush letters to try to come up with a combination of words to achieve the "clean plate" achievement within Smush. Smooshy has no official affiliation with Smush, John Green, or Hank Green.

How Smooshy works:

1. Input Letters: Start by typing 9 unique letters into the Letter Pool prompt using the letters provided in the Smush letter grid. Make sure to enter the 'golden' letter last.

2. Tile Generation: As soon as the 9th letter is added, the pool will generate 5 blue tiles for each of your first 8 letters, and 1 special pink tile for the 9th 'golden' letter.

3. Objective: Drag tiles from the Letter Pool into the Workspace to form valid words. Each word should contain at least one pink tile. Each row contains one word. If you use up all of the blue tiles, use at least one pink tile in every row, and all rows contain valid words, you achieve a "clean plate".

4. Dragging Tiles to the Workspace: Dragging a blue tile from the Letter Pool into the Workspace removes that tile from the Letter Pool. Dragging the pink tile from the Letter Pool into the Workspace creates a new copy of that tile. You may create as many copies of the pink tile as you need.

5. Dragging Tiles from the Workspace: Dragging a blue tile from the Workspace to the Letter Pool returns that tile to the Letter Pool. Dragging a pink tile from the Workspace to the Letter Pool deletes that copy of the pink tile from the Workspace.

6. Dragging Tiles within the Workspace: Tiles can be dragged within the Workspace to change their order within a row or to move them from one row to another.

7. Validating Words: If a dictionary.txt file has been loaded, Smooshy will use it to validate whether the word in a given row is valid according to the loaded dictionary file. You can load an official word database such as the Official North American Scrabble Dictionary to use as your dictionary file. Open the link, click the "Download raw file" button on that page, rename the saved file on your computer to 'dictionary.txt', and drag and drop it into the designated zone at the top of the Smooshy app. Smooshy will cache the dictionary file and use it to validate words as you enter them in the Workspace.

8. Points: Smooshy will calculate the basic Scrabble point value of each word you assemble in the Workspace. It will not calculate any bonus points that Smush may award you for using certain 'spicy' letters or for 'smushing' any of the letters you used. It will not calculate points for any bonus achievements.
